## 🌟 Overview

**Islamic Azkar Pro** is a high-performance, single-bundle Islamic web application built specifically for Muslims seeking an authentic, distraction-free, and fully offline sanctuary for daily worship.

It operates with **zero external API dependencies**, has **no telemetry or tracking**, stores all personal prayer counts safely in local storage, and works across Android, iOS, Windows, macOS, and Linux.

---

## ✨ Key Features

### 1. Authentic 26 Mubarak Surahs & Quranic Recitation
- **26 Mubarak Surahs**: Full Arabic text of high-virtue Surahs (Surah Al-Fatihah, Ayat-ul-Kursi, Surah Al-Baqarah Ruku 1 & Last, Ali 'Imran Last Ruku, Al-Kahf, As-Sajdah, Yaseen, Ad-Dukhan, Al-Fath, Qaf, Ar-Rahman, Al-Waqiah, Al-Hadid, Al-Hashr, As-Saff, Al-Jumu'ah, At-Taghabun, At-Tahrim, Al-Mulk, Nuh, Al-Jinn, Al-Muzzammil, Al-Qiyamah, Ad-Dahr, and more).
- **Authentic Pakistani Mushaf Typography**: Traditional floral/ornate verse brackets (`﴿۱﴾`) with complete preservation of waqf symbols (waqf jeem `ۚ`, waqf lazim `ۘ`/`ۙ`, waqf mutlaq `ؕ`).
- **Surah Virtues (فضائل و برکات)**: Glowing animated highlight button (`fazPulse`) providing authentic Hadith virtues framed with strict reverent adab.
- **Dual Reading Modes**: Seamless toggle between continuous paragraph reading and verse-by-verse recitation.
- **5-Speed Auto-Scroll Engine**: Hands-free recitation speed controller across all chapters.
- **6 Bundled Offline Fonts**: Al Majeed, Hafs, Al Qalam, PDMS Saleem, Muhammadi, and Al Mushaf.

### 2. High-Demand Durood Sharif Collection
- **80x Friday Asr Darood Counter**: Specialized counter for the 80-year forgiveness tradition.
- **Durood-e-Ibrahimi Counter**: Complete Arabic text, virtues from Hadith, and customizable counter.
- **Durood-e-Tanjeena**: Famous relief supplication for difficulties, storms, and trials.
- **Durood-e-Taj**: Full authentic devotional text for spiritual peace and blessings.

### 3. Masnoon Supplications & Daily Adhkar
- **After Fard Salah Azkar**: Authentic post-prayer supplications (Istighfar ×3, Ayatul Kursi, Tasbeeh Fatima, Mu'awwidhat, and Dua for Hasanah).
- **Bedtime Azkar (سونے کے اذکار)**: Ayatul Kursi, Amanar-Rasul, 3 Quls with Dam guidance, and bedtime supplication.
- **Morning Waking Azkar**: Authentic praise upon awakening and Tahajjud Tawheed kalima.
- **Debt Relief & Anxiety Duas**: Authentic prophetic prayers for heavy debts and sorrow.
- **Dua-e-Istikhara**: Complete prophetic text, translation, and step-by-step guidance for major life decisions.
- **Sayyidul Istighfar & Tawbah**: Leader of repentance prayer with promise of paradise.
- **Tasbeeh-e-Fatima (33-33-34)**: Automatic 3-phase counter with haptic and audio completion chimes.
- **40 Rabbana Duas (۴۰ ربنا)**: The complete 40 authentic Quranic supplications starting with Rabbana.

### 4. Asma-ul-Husna (99 Names of Allah)
- **Complete 99 Beautiful Names of Allah**: Luxury responsive cards with Arabic typography, authentic Urdu meanings, and Hadith virtue citation.
- **Integrated Wird Catalog**: Import any divine name directly into your personal list.

### 5. Custom Azkar Builder (ذاتی اذکار)
- **1-Tap Category Access**: Direct "📝 ذاتی اذکار" button in the category selector bar.
- **Personalized List**: Add custom duas or wird with target counts (33, 70, 100, 313, 1000).
- **Sequential Flow**: Step-by-step Next/Back navigation matching regular azkar sections.
- **JSON Backup & Share**: Export your custom prayers to a `.json` backup file or copy formatted text for WhatsApp/Notes sharing.

### 6. Wallpapers & Eye Comfort
- **Real Open-Source Wallpapers**: Genuine high-definition photographic textures:
  - Holy Kaaba at Night (`assets/wallpapers/kaaba.webp`)
  - Masjid an-Nabawi Dome & Minarets (`assets/wallpapers/nabawi.webp`)
  - Islamic Architectural Mosaic Arch (`assets/wallpapers/arabesque.webp`)
  - Custom Wallpaper Upload with smooth opacity dimmer slider.
- **Masjid Mode (Silent & Haptic)**: Mutes audio beeps and relies strictly on subtle vibrations.
- **Eye-Comfort Themes**: Default Emerald Night, pure AMOLED Black (`#000000`) for OLED battery savings, and Warm Sepia.

## ⌨️ Keyboard Shortcuts

For desktop users, the app offers complete keyboard navigation:

| Key | Action |
| :--- | :--- |
| `Space` or `Enter` | Increment counter (Tap) |
| `Backspace` | Undo last count |
| `Arrow Right` (`→`) | Next supplication (اگلا ذکر) |
| `Arrow Left` (`←`) | Previous supplication (پچھلا ذکر) |
| `+` / `Numpad +` | Zoom in Quranic / Arabic font |
| `-` / `Numpad -` | Zoom out Quranic / Arabic font |

## 🔒 UI Architecture Lock (Strict Directive)

The visual design, component layout, and user experience of **Islamic Azkar Pro** are **permanently frozen and locked**. All AI agents and human contributors must preserve the existing interface layout:

- **Locked Elements**:
  1. **Top Bar**: Streak badge (`🔥 X دن`), direct 1-tap sound toggle (`🔔`/`🔇`), glassmorphic zikr selector pill (`[ ☀️ ذکر منتخب کریں ▾ ]`), and three-dot settings trigger (`⋮`).
  2. **Spiritual Greeting Banner**: Pure timeless text with zero numbers or prayer hours.
  3. **Reading Counter**: Luxury emerald counter ring with haptic animation, centered clean typography, and dua cards.
  4. **Welcome Dashboard**: 7-card grid with Islamic greeting and direct guidance.
  5. **Completion Screen**: Seamless restart (`↺ دوبارہ شروع کریں`) and home navigation (`🏠 مرکزی صفحہ`).
  6. **Unified Settings Modal**: Glassmorphic card sections (Zoom, Quran font, Audio, Themes, Kahf preferences) and footer (`محفوظ کریں ✓` + `📲 ایپ انسٹال کریں`).

- **Permitted Additions**:
  1. Adding new Azkar / Supplications into the catalog.
  2. Adding new settings options inside the existing three-dot settings modal.
  3. Performance, offline service worker, and bug fix enhancements.

## 💻 Local Development

No build tools, bundlers, or package installations are required.

```bash
# Clone the repository
git clone https://github.com/jamamjadalone/islamic-azkar-pro.git

# Navigate into directory
cd islamic-azkar-pro

# Start a local static server
python -m http.server 8080
```

Open `http://localhost:8080` in your browser.

> [!NOTE]
> Run using a local web server rather than opening `file:///` directly so that Service Worker registration and PWA features initialize properly.
