# Tanzil Quran Text Credits

Uthmani Quran text (used for the full 114-surah reader, `quran/full/surah_N.json`):

- Source: **Tanzil — quran-text files**, https://tanzil.net/download
- Text version: `tanzil-1.1-uthmani` (recorded in `surahs_meta.json` by
  `quran/full/tools/tanzil-convert.js`)
- Attribution: Tanzil text used with proper credits as required by the
  Tanzil usage terms; the text is served/converted unmodified in content
  (conversion only formats it into per-surah JSON for offline caching).

IndoPak (Pakistani Mushaf) text is credited separately in
`CREDITS-indopak.md` (same folder).

Meta files (`surahs_meta.json`, `surahs_index.json`, `paras_index.json`,
`manifest_15line.json`, `manifest_16line.json`) are project-authored
navigation metadata, not third-party text.

Notes

- 15-line / 16-line para manifests reference externally hosted mushaf page
  images which are NOT bundled in this repository; no page-scan image rights
  are involved in the repo contents.
- If you are a rights holder and object to this usage, open an issue and the
  affected data will be removed immediately.
