# Defaults to avoid

These are the looks an AI produces when nobody decided anything. A person who has seen a few AI-made apps recognises them at once.

This is a list to check against, not a list of bans. Banning one default only brings the next one. What works is a real decision: an exact value with a reason that comes from this app. And the user's own words always win. If they ask for a dark screen with a green accent, that is their choice, not a default.

This list goes out of date as models change. Update it when a new look starts to repeat.

## Whole looks

- **Cream and serif:** an off-white or cream background, serif headings, one word in italics, a terracotta or orange accent.
- **Black and neon:** a near-black background with one acid green, cyan or orange accent, and grey body text.
- **Purple gradient:** a purple or indigo main colour, purple-to-blue gradients, gradient text, glowing shadows.
- **Newspaper:** thin rules everywhere, no rounded corners, dense columns, small capitals.
- **The untouched kit:** a component library used exactly as it comes, with its default colours, radius and font.

## Layout habits

- A centred heading with a small pill above it and three identical cards with an icon on top.
- Every group of content in a card with the same radius and the same soft shadow. Cards inside cards.
- A coloured stripe on the left or the top edge of cards.
- A row of big numbers with nothing to compare them to.
- Every section built the same way, with the same spacing.

## Details

- Emoji used as icons or bullets. A sparkle icon for anything "smart".
- Small all-capitals labels above headings. Numbers like 01, 02, 03 on things that are not steps.
- An arrow on every button.
- Glass and blur effects on panels.
- Everything fading and sliding up as it appears. A hover effect on every card.

## Fonts

- One font for everything, chosen because it is the usual one: Inter, Roboto, the system font.
- The usual "different" fonts chosen for the same reason: Space Grotesk, Geist, Instrument Serif, Fraunces, Playfair Display.

Choose a font for what it does in this app: how readable its numbers are in a table, how it holds up small on a phone, whether its character suits the subject. Use fonts the app is allowed to ship: system fonts or fonts with an open licence. Always name a fallback.

## Words

- Text that could describe any product: "seamless", "powerful", "all-in-one".
- Buttons that say "Submit" or "Continue" where a real name fits, such as "Save alert rule".
- Placeholder text. Use the app's real names and realistic numbers.
