# Security Policy

The security of Islamic Azkar Pro and its users is a priority. This project is a static client-side web application served from GitHub Pages; it contains no server-side code, databases, or user authentication.

## Supported Versions

Only the latest version deployed to `main` is supported. We do not maintain backports of older releases.

## Reporting a Vulnerability

Please **do not** open a public issue for security problems. Report privately instead:

- Open a [GitHub Security Advisory](https://github.com/jamamjadalone/islamic-azkar-pro/security/advisories/new) ("Report a vulnerability"), **or**
- Contact the maintainer privately through the GitHub issue tracker with the **Security** label.

### What to include

- Affected file(s) and section (e.g., `index.html` — service worker)
- A description of the vulnerability and its potential impact
- Steps to reproduce, if applicable
- Suggested fix, if you have one

### What to expect

- Acknowledgment within **72 hours**
- Status update within **5 business days**
- A coordinated disclosure once a fix is released

Thank you for helping keep this project secure.
